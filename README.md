# SonicState

SonicState enables distributed real-time data processing and auto-scaling clusters for high-performance event-driven applications.

With SonicState, you get a lightweight tool that stays out of your way.

**What you get**

- SonicState enables distributed real-time data
- processing and auto-scaling clusters for
- high-performance event-driven applications

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/SonicState.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
